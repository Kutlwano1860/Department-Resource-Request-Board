# PM-04 Final Project: ResourceHub

## Project Option
I selected: Department Resource Request Form

## Project Description
ResourceHub helps a team lead or department capture resource requests (equipment, software access, stationery, training material, meeting support) and track them from Submitted to Approved to Resolved.

## Features
- Request form with validation
- Request board with three stages
- Dashboard stats and progress bar
- Search and urgency filter
- Saved data (localStorage) and CSV export
- Dark and light theme

## JavaScript Concepts Used
- Variables
- Functions
- Arrays and objects
- Conditions
- Loops
- Events
- DOM manipulation
- Validation

## How to Use the Project
1. Open index.html in a browser.
2. Fill in the request form and click Submit request.
3. Move requests between columns with the buttons or by dragging.
4. Use Export CSV to download all requests.
